### ⚙️ PHẦN 3: VIBE LOGIC & CÔNG NGHỆ ĐỘT PHÁ (01:00 - 01:45)
> *"Về mặt kỹ thuật, dự án được triển khai theo mô hình **Agile / Scrum kết hợp Vibe Coding** với 3 module Clean Code độc lập (`data.js`, `ui.js`, `app.js`) và đạt 100% tiêu chí **Definition of Done (DoD)**:*  
> * **1. 100% Dynamic JSON Render:** Toàn bộ 16+ thiết bị được nạp động từ file `data/products.json` với cơ chế DataLoader bất đồng bộ có fallback offline an toàn.*  
> * **2. Live Search với thuật toán Debounce 250ms:** Tìm kiếm theo thời gian thực mượt mà, triệt tiêu hoàn toàn hiện tượng giật lag khung hình khi gõ nhanh.*  
> * **3. Bộ lọc kết hợp đa chiều (Multi-Filter):** Cho phép sinh viên lọc đồng thời Danh mục + Khoảng giá + Badge ưu đãi + Sắp xếp giá/đánh giá.*  
> * **4. Real-time Form Validation:** Kiểm tra trực tiếp từng phím gõ bằng biểu thức chính quy (Regex) chuẩn MSSV LHU và số điện thoại Việt Nam, xuất mã vận đơn điện tử lưu vào LocalStorage.*  
> * **5. Trải nghiệm nâng cao:** Hỗ trợ Dark Mode bảo vệ mắt ban đêm, danh sách yêu thích Wishlist và hộp thoại Agile Inspector trực quan ngay trên web."*
